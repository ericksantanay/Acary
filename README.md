# 👶 Acary - Plataforma de Conexão para Babás

O **Acary** é uma aplicação web desenvolvida para facilitar a conexão entre pais e profissionais de cuidados infantis (babás). O objetivo principal do projeto foi construir uma solução full stack completa, desenvolvida especialmente para dispositivos móveis (mobile), com foco em segurança de dados, autenticação de usuários e interface amigável.

> 🚀 **Status do Projeto:** Hospedado / Em desenvolvimento contínuo.

---

## 🛠️ Tecnologias Utilizadas

### **Front-end**
* **HTML5** (Estruturação da página)
* **CSS3** (Estilização e responsividade focada em mobile)
* **TypeScript (TS)** (Lógica do cliente e tipagem estática)

### **Back-end & Banco de Dados**
* **Node.js** (Ambiente de execução back-end)
* **MongoDB** (Banco de dados NoSQL)
* **JWT (JSON Web Token)** (Autenticação e autorização segura)
* **Bcrypt / Criptografia** (Proteção de senhas de usuários no banco)

---

## 🔒 Segurança e Funcionalidades Implementadas

- [x] **Interface Otimizada para Mobile:** Layout e usabilidade desenvolvidos especialmente para smartphones.
- [x] **Autenticação Segura:** Cadastro e login de usuários com senhas totalmente criptografadas.
- [x] **Controle de Acesso:** Emissão de tokens JWT para navegação e rotas autenticadas.
- [x] **Banco de Dados Integrado:** Persistência de dados dinâmica utilizando MongoDB.
